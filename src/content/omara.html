01 · Welfare application review

Help officers review applications and resolve gaps

Government officers processed welfare applications submitted offline. I designed a review platform to support that work and give officers a way to request clarifications when information was missing.

The context

The workflow needed to bring offline applications into an officer-facing review experience.

The design response

The platform included a clarification request so an officer could follow up when application information was incomplete.

02 · Design-system tooling

Turn design-system work into reusable skills

Review and fix UI components

I built a Claude Code skill to review and fix UI components and documentation against internal standards, improving quality and reducing manual effort.

Generate high-fidelity prototypes

A second Claude Code skill generates high-fidelity Figma prototypes from design-system components, reducing prototype time from hours to minutes.

Outcome

Make good work easier to repeat

The review platform addressed a practical gap in offline application processing, while the two design-system skills made routine quality checks and prototype creation more efficient.
